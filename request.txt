二、项目开发背景与目的（文档开头直接抄）
本项目为个人学习开发的自用 Web 项目，采用当前主流前后端分离架构，后端使用 SpringBoot+MyBatis 实现业务数据持久化管理，Vue 搭建前端交互页面，MySQL 存储结构化朋友数据，Redis 做数据缓存与向量临时存储；独立使用 Python 搭建 LangChain 智能 Agent 服务，实现对话历史记忆、文本向量嵌入、朋友信息向量匹配检索功能。
项目主要用于个人日常记录、整理身边每位朋友的各类信息、生活小事、零散备忘内容，同时借助大模型 + 向量检索实现智能问答、信息快速回忆，同时全程练习 SpringBoot 开发、Vue 前端开发、数据库运用、Python LangChain 智能体开发、跨服务接口联调的完整实战能力。

三、整体技术架构（自用学习版，精简好开发，文档可直接写）
1. 整体架构模式
前后端分离 + 业务服务与 AI 智能服务分离

前端：Vue3 + Element Plus + Axios（页面展示、所有信息录入、AI 对话交互）
业务后端：SpringBoot + MyBatis + MySQL + Redis只做核心业务：朋友信息增删改查、便签记录管理、数据缓存、向前端提供业务接口、调用 Python AI 服务接口、存储对话历史记录
AI 智能服务：Python + LangChain + FastAPI独立部署运行，专门负责：文本向量生成、朋友信息向量库存储、历史对话记忆管理、Agent 智能问答、相似度提示词匹配检索
跨服务通信：HTTP 接口互相调用，结构清晰，学习练手最舒服，互不干扰

六、整套业务运行流程（文档必须写，画流程图也能用）

前端页面录入朋友基础信息 / 喜好 / 便签记事
SpringBoot 后端接收数据，存入 MySQL 数据库
后端调用 Python FastAPI 提供的接口，把新增的文本数据传给 AI 服务
Python LangChain 端接收数据，生成文本向量，存入Redis库
用户在前端发起 AI 提问查询朋友相关信息
请求先传到 SpringBoot 后端，再转发给 Python AI 服务
Python 端执行流程：读取当前会话历史记忆 → 对提问内容生成向量 → 在向量库做相似度匹配 → 捞出相关的朋友原始记录 → 拼接专属提示词 → LangChain Agent 结合历史对话 + 检索内容生成回答
AI 回答结果原路返回，后端保存本次对话记录到 MySQL，前端展示回答内容
